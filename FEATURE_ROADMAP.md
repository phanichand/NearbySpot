# NearbySpot -- Feature Roadmap

## Phase 2: Along-the-Route (High Impact)

- [ ] **Along-the-Route Suggestions** -- Enter a destination, app shows great stops along your route with detour time estimates. Sample waypoints along the polyline, run searchNearby at each, filter by detour cost.
- [ ] **Saved / Favorites** -- Bookmark places to visit later. Store in Room DB. Show a "Saved" tab or screen.
- [ ] **"Surprise Me" Button** -- One tap picks the single best place for the selected category and starts navigation immediately.

## Phase 3: Polish + Engagement (Medium Impact)

- [ ] **Photo Previews in Bubbles** -- Show a small place photo in each bubble card using the Places Photo API. Big visual upgrade.
- [ ] **Open Now Filter** -- Toggle to only show places currently open. Critical at night or early morning.
- [ ] **Sort Options** -- Let users sort by: rating, review count, distance, or default smart score.
- [ ] **Search History / Recent Places** -- Show recently searched categories and viewed places for quick re-access.
- [ ] **Multi-Category Search** -- Select multiple categories together (e.g., "Restaurant + Cafe") to see both types in one search.
- [ ] **Dark Mode Map** -- Switch the Google Map to a dark style when the app is in dark theme.

## Phase 4: Differentiators (Future)

- [ ] **Trip Planner** -- Build a full-day itinerary: breakfast, morning attraction, lunch, afternoon activity, dinner. Chain suggestions with travel time between each stop.
- [ ] **Offline Mode** -- Cache results and map tiles for areas with poor connectivity (common for tourists abroad).
- [ ] **Share a Place** -- Share a deep link or formatted card via WhatsApp/messages so friends can see the recommendation.
- [ ] **Language-Aware Reviews** -- Filter reviews by language so tourists can read reviews they understand.
- [ ] **Crowd Insights** -- Use Google's "popular times" data to suggest less crowded alternatives.
- [ ] **Budget Tracker** -- Set a daily food budget; the app factors price level into suggestions to keep you on track.
